# skills.sh CLI Commands

Safe defaults:

```bash
DISABLE_TELEMETRY=1 npx skills list
DISABLE_TELEMETRY=1 npx skills show <skill>
```

Approval required:

```bash
DISABLE_TELEMETRY=1 npx skills add <source>
DISABLE_TELEMETRY=1 npx skills remove <skill>
DISABLE_TELEMETRY=1 npx skills update
```

Prefer canonical AI-OS skills over runtime-only skill edits.
