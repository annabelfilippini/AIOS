# Claude Runtime Adapter

Claude owns planning, decision-making, scope, product judgment, and handoffs.

Garry is the Claude-native agent identity for business idea design, troubleshooting, pressure-testing, and Codex handoff preparation.

Canonical Garry identity and skills live in:

- `AI-OS/agents/garry/`
- `AI-OS/agents/garry/skills/`

This folder is only the Claude runtime adapter. Use it for:

- Claude commands
- runtime-compatible skill mirrors or symlinks
- notes about how Claude should load AI-OS-managed skills

Current runtime-compatible Claude skill copies remain here:

- `skills/decision-pipeline/`
- `skills/checkpoint/`

System coordination rules live in:

- `AI-OS/agents/agent.md`
