# Annie Inbox

Drop raw requests, captures, notes, and "Annie, handle this" items here.

Annie should turn inbox items into one of:

- a draft in `workspace/drafts-for-approval/`
- a brief in `workspace/client-briefs/`
- meeting notes in `workspace/meeting-notes/`
- a report in `workspace/reports/`
- a reusable template or SOP
- a project-specific update in `AI-OS/projects/<project>/`
