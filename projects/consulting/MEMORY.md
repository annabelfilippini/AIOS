# Consulting — Decision Memory

Running log of major decisions for the consulting business. Update whenever a big decision is made (positioning, pricing, pilots, target market, offer structure, tooling commitments, naming, partnerships, or anything that changes direction).

## How to use

- Append new decisions at the top under `## Decisions` with the date, the decision, and the reasoning.
- Keep entries tight: what was decided, why, and what it replaces or changes.
- If a prior decision is reversed, leave the original in place and add a new entry that supersedes it (note which one).

## Format

```
### YYYY-MM-DD — <short title>
**Decision:** <what was decided>
**Why:** <reasoning, constraints, or evidence>
**Supersedes:** <prior decision title, if any>
```

### 2026-04-27 — Standardize 30-day pilot delivery kit
**Decision:** Use a lightweight internal pilot delivery kit for consulting engagements: one named workflow, one success signal, one reusable pattern, and one scheduled 30-day review. Marta Brummell is the first example implementation plan.
**Why:** The consulting project already had strong positioning, a canonical engagement playbook, and rich prospect notes, but pilot execution needed a repeatable path from discovery to build to review. Standardizing the kit reduces sprawl while keeping each pilot narrow and case-study-ready.
**Supersedes:** None
