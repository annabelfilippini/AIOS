# Revero Redesign Brief

Status: draft strategy pass, not yet approved for build.

## Recommended Offer Shape

Website Trust Refresh + Enrollment Flow Coordination

This mirrors the Vital Health lesson: the visible public site needs a cleaner,
more trustworthy presentation, but the work should not pretend to rebuild the
medical app, onboarding system, payments, labs, devices, or support system.

## Best First Scope

Phase 1: Public Website Trust Refresh

- Rebuild the homepage and core public pages with clean section hierarchy.
- Fix copy, grammar, headings, CTAs, and trust flow.
- Create a claims matrix for all outcome, disease, pricing, and availability
  statements.
- Keep onboarding, login, info call, phone, and support links routed to the
  existing systems.
- Build a static HTML preview first so Annabel can judge direction quickly.

Phase 2: Editable Platform Decision

- If Revero wants nontechnical team editing, rebuild approved public pages in
  Webflow or another CMS.
- If Revero's marketing team needs funnel-platform analytics/experiments, keep
  ClickFunnels or current platform and use the refresh as a rebuild spec.
- Either way, QA staging before live.

Phase 3: Enrollment Workflow QA

- Test handoff from public site to onboarding, free info call, phone, support,
  and login.
- Standardize CTA labels and destination logic.
- Confirm tracking/paid-search requirements before launch.

## Suggested Page Set

- Home
- How It Works
- What We Treat
- Membership
- Success Stories
- FAQ
- For Providers or Research
- About

## Direction

The site should feel less like a supplement funnel and more like a modern
virtual specialty clinic:

- Clean, clinical, human.
- Calm hierarchy.
- Fewer claims per screen.
- Stronger proof architecture.
- Founder credibility without making the whole brand depend on one personality.
- Clear "join" versus "talk to us" paths.

## Build Gate Before HTML Preview

Do not write final medical copy until these are answered:

- Approved conditions and availability.
- Approved patient outcome claims.
- Approved membership pricing details.
- Whether "reverse" language is allowed.
- Whether testimonials need disclaimers.
- Which platform is preferred for the final public site.

## HTML Preview Scope

When Annabel says go, build only the homepage preview first.

The preview should not use real patient photos beyond assets already public on
the Revero site unless there is explicit permission. It can use public extracted
assets as placeholders, but the handoff should flag image rights and approval.
