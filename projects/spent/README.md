# Spent

Spent is a tiny iPhone app for logging purchases in a few seconds.

## V1

- Add amount and item
- Automatically store the date/time
- Show today's total
- Show this month's total
- Show recent purchases
- Delete accidental entries

## Open In Xcode

Open `Spent.xcodeproj`, select an iPhone simulator or your phone, and run.

This machine currently has Apple Command Line Tools selected instead of full Xcode, so terminal builds with `xcodebuild` will not work until Xcode is installed and selected.

## Sharing Later

Use TestFlight first for sisters/family testing. Once the app feels useful for a few weeks, submit the same app to the App Store if desired.
