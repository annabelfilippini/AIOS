# Research

Single home for everything that informs Annabel's paid audit: source material, synthesis notes, and the working templates the audit ships as.

## Folders

- `sources/` — raw captures (Mansel, Bo, Mark Kashef) and original interview / module bodies. Authoritative input.
- `templates/` — the working artifacts that go to clients (`paid-audit-playbook.md` is the main deliverable spec; `quick-read.md` is the free funnel; the rest are partner / prospect / offer-brief templates).
