How it works — three sources, joined

flightconnections.com

Which routes exist

Direct-destination map per airport via internal JSON. Cheap pre-filter — answers "is there a nonstop", not price.

Google Flights

What it costs

Real price/airline/duration for an exact date via fast-flights + a local headless browser. Slow, so only the survivors get priced.

windguru.cz

Is the wind good

Live GFS forecast (knots) per spot, ~16-day horizon. Hard-filters spots below 12 kt and ranks the rest. Now its own connector — cli-connections/windguru/ (docs + scripts), stdlib-only, no key.
